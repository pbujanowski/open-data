# open-data-dashboard-service

NestJS backend service for the Dashboard APIs in the Open Data platform.

## Development

- Start dev server: `yarn start:dev`
- Build: `yarn build`
- Test: `yarn test`
- Lint: `yarn lint`
- Format: `yarn format`

## Environment

See `.env.development` for required environment variables.

## Usage

This service is typically run as part of the full Open Data platform. See the root README for details.
