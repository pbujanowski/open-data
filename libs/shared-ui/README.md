# open-data-shared-ui-lib

Reusable React UI components and utilities for the Open Data monorepo.

## Usage

Import components from this library in your client apps:

```tsx
import { Layout } from '@open-data/shared-ui-lib';
```

## Development

- Run tests: `yarn test`
- Lint: `yarn lint`
- Format: `yarn format`
- Build types: `yarn build`

See the root README for monorepo-wide commands and setup.
